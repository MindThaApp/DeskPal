# Desk Pal 1.2 Store listing: ja-jp

## Title
Desk Pal

## Hook
Bloopと一緒に、ストレッチ・水分補給・目の休憩をやさしくお知らせ

## Short description
タスクトレイに住むフレンドリーなパートナー。ストレッチ、水分補給、目の休憩、体を動かすタイミングを、あなたの一日に合わせてお知らせします。

## Description
Desk Pal は、Windows のタスクトレイに住むフレンドリーなパートナーです。仕事中の自分のケアをそっとサポートします。

デスクワークの長い一日は、肩のこり、目の疲れ、水の飲み忘れとなって積み重なります。Desk Pal は、ストレッチ、水分補給、目の休憩、ちょっとした散歩を、ちょうどよいタイミングでやさしくお知らせします。陽気な青いかたまりの Bloop が各ストレッチを見せてくれて、小さな鉢植えの Sprout は、毎日の目標を達成するほどすくすく育ちます。

あなたの一日を尊重するお知らせ
• スマートなスケジュールがリマインダーをまとめるので、通知があふれることはなく、1 時間あたりの回数も適度に保たれます。
• 通話中、Focus Assist がオンのとき、フルスクリーンのアプリを実行中のときは待機して、もっと良いタイミングを選びます。
• ほしいリマインダーと頻度を選べます。おすすめの間隔が表示され、すべて調整できます。
• 目の休憩は、よく知られた 20-20-20 の考え方に沿って、うるさいポップアップではなく画面上の控えめな合図でお知らせします。

Bloop と Sprout
• Bloop はライブ 3D ビューでストレッチを見せてくれて、つついたり、なでたり、遊んだりすると反応します。
• Sprout が進み具合を記録するので、休憩を終えることが義務ではなく、ちょっとした達成感になります。
• 罪悪感なし:休憩を逃してもペナルティは一切ありません。

デスクトップのために
• トレイアイコンからのクイックパネル、今日の進み具合が分かる専用ウィンドウ、シンプルな設定ページ。
• ライトテーマ/ダークテーマに対応します。
• 休憩や集中時間であなた自身のオートメーションを動かしたいときは、Automation Portal と連携できます。オンにするまでは無効です。
• 20 言語に対応。設定でいつでも切り替えられます。

設計段階からプライベート
• アカウント不要、広告なし、トラッキングなし。進み具合はお使いの PC に保存されます。
• クラッシュレポートは、許可した場合のみ送信されます。

Desk Pal は、一般的なウェルビーイングのヒントとリマインダーを提供します。医療機器ではなく、医学的なアドバイスは行いません。

## Features
- ストレッチ・水分補給・目の休憩・散歩をやさしくお知らせ
- 通話中、Focus Assist 中、フルスクリーン中は待機
- Bloop が各ストレッチをライブ 3D で見せて、遊ぶと反応
- リマインダーと間隔を選べて、おすすめ値も表示
- アカウント不要、広告なし、トラッキングなし。進捗は PC に保存
