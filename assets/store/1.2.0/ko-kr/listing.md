# Desk Pal 1.2 Store listing: ko-kr

## Title
Desk Pal

## Hook
Bloop과 함께, 스트레칭·물 마시기·눈 휴식을 부드럽게 알려 드려요

## Short description
알림 영역에 사는 친근한 동반자가 스트레칭, 물 마시기, 눈 쉬기, 움직임을 하루에 맞는 순간에 챙겨 줘요.

## Description
Desk Pal은 Windows 알림 영역에 사는 친근한 동반자로, 일하는 동안 스스로를 돌볼 수 있도록 도와줘요.

책상 앞에서 보내는 긴 하루는 쌓이기 마련이에요. 뻣뻣한 어깨, 피곤한 눈, 깜빡한 물 한 잔까지요. Desk Pal은 스트레칭, 물 마시기, 눈 쉬기, 짧은 산책을 알맞은 때에 부드럽게 알려 줘요. 명랑한 파란 방울 Bloop이 스트레칭을 하나하나 보여 주고, 작은 화분 Sprout은 매일의 목표를 지킬수록 쑥쑥 자라요.

하루를 존중하는 알림
• 스마트 일정이 알림을 하나로 합쳐서 알림이 쏟아지는 일이 없고, 한 시간에 적당한 횟수만 보내요.
• 통화 중이거나, Focus Assist가 켜져 있거나, 전체 화면 앱이 실행 중이면 기다렸다가 더 좋은 때를 골라요.
• 원하는 알림과 간격을 직접 고르세요. 권장 간격이 표시되고, 모든 것을 조정할 수 있어요.
• 눈 휴식은 인기 있는 20-20-20 방식을 따르며, 시끄러운 팝업 대신 화면에 조용한 신호를 보여 줘요.

Bloop과 Sprout
• Bloop은 실시간 3D 화면으로 스트레칭을 보여 주고, 콕콕 찌르거나 쓰다듬거나 놀아 주면 반응해요.
• Sprout이 진행 상황을 기록해서, 휴식을 마치는 일이 숙제가 아니라 작은 성취처럼 느껴져요.
• 죄책감은 없어요. 휴식을 놓쳐도 벌은 없답니다.

데스크톱을 위해 만들었어요
• 알림 영역 아이콘에서 여는 빠른 패널, 오늘의 진행 상황을 보는 전체 앱 창, 간단한 설정 페이지가 있어요.
• 밝은 테마와 어두운 테마를 따라가요.
• 휴식이나 집중 시간으로 나만의 자동화를 실행하고 싶다면 Automation Portal과 함께 쓸 수 있어요. 직접 켜기 전까지는 꺼져 있어요.
• 20개 언어를 지원하며, 설정에서 언제든 바꿀 수 있어요.

설계부터 개인정보 보호
• 계정, 광고, 추적이 없어요. 진행 상황은 내 PC에만 저장돼요.
• 충돌 보고서는 허용한 경우에만 전송돼요.

Desk Pal은 일반적인 웰빙 팁과 알림을 제공해요. 의료 기기가 아니며 의학적 조언을 제공하지 않아요.

## Features
- 스트레칭, 물 마시기, 눈 쉬기, 걷기를 부드럽게 알려 줘요
- 통화 중, Focus Assist, 전체 화면에서는 기다려요
- Bloop이 실시간 3D로 스트레칭을 보여 주고 놀아 주면 반응해요
- 알림과 간격을 고르고, 권장값도 함께 볼 수 있어요
- 계정, 광고, 추적 없음. 진행 상황은 내 PC에만 저장돼요

• 앱 전체의 움직임이 더 부드러워졌어요.
