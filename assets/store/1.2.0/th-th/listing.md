# Desk Pal 1.2 Store listing: th-th

## Title
Desk Pal

## Hook
เตือนเบา ๆ ให้ยืดเส้น ดื่มน้ำ และพักสายตา พร้อม Bloop

## Short description
เพื่อนใจดีในถาดระบบที่คอยเตือนให้คุณยืดเส้น จิบน้ำ พักสายตา และขยับตัว ในจังหวะที่เหมาะกับวันของคุณ

## Description
Desk Pal คือเพื่อนใจดีที่อยู่ในถาดระบบของ Windows คอยช่วยให้คุณดูแลตัวเองระหว่างทำงาน

การนั่งโต๊ะทำงานทั้งวันสะสมได้หลายอย่าง ทั้งไหล่ตึง ตาล้า และลืมดื่มน้ำ Desk Pal จะเตือนอย่างอ่อนโยนในจังหวะที่เหมาะสมให้คุณยืดเส้น ดื่มน้ำ พักสายตา และเดินสั้น ๆ Bloop ก้อนกลมสีฟ้าอารมณ์ดี จะสาธิตท่ายืดเส้นให้ดูทีละท่า ส่วน Sprout ต้นไม้กระถางเล็ก ๆ จะเติบโตเมื่อคุณทำเป้าหมายประจำวันได้ต่อเนื่อง

การเตือนที่เคารพวันของคุณ
• ตารางเวลาอัจฉริยะรวมการเตือนเข้าด้วยกัน คุณจึงไม่โดนเตือนถี่เกินไป และจำกัดจำนวนต่อชั่วโมงให้พอเหมาะ
• Desk Pal จะรอเมื่อคุณอยู่ในสาย เมื่อตัวช่วยโฟกัสเปิดอยู่ หรือเมื่อมีแอปเต็มหน้าจอทำงานอยู่ แล้วค่อยเลือกจังหวะที่ดีกว่า
• เลือกได้ว่าต้องการการเตือนแบบไหนและบ่อยแค่ไหน มีค่าเวลาที่แนะนำให้ดู และปรับได้ทุกอย่าง
• การพักสายตาใช้แนวคิด 20-20-20 ที่รู้จักกันดี ด้วยสัญญาณเงียบ ๆ บนหน้าจอ แทนป๊อปอัปที่เสียงดัง

Bloop และ Sprout
• Bloop สาธิตท่ายืดเส้นในมุมมอง 3D แบบสด และตอบสนองเมื่อคุณสะกิด ตบเบา ๆ หรือเล่นกับมัน
• Sprout ติดตามความก้าวหน้าของคุณ ทำให้การพักเสร็จสิ้นรู้สึกเหมือนความสำเร็จเล็ก ๆ ไม่ใช่งานน่าเบื่อ
• ไร้ความรู้สึกผิด: พลาดการพักไปก็ไม่มีการลงโทษใด ๆ

ออกแบบมาเพื่อเดสก์ท็อปของคุณ
• แผงด่วนจากไอคอนในถาดระบบ หน้าต่างแอปเต็มรูปแบบสำหรับดูความก้าวหน้าของวันนี้ และหน้าการตั้งค่าที่เรียบง่าย
• เปลี่ยนตามธีมสว่างหรือมืดของคุณ
• ทำงานร่วมกับ Automation Portal หากคุณต้องการให้การพักหรือเวลาโฟกัสเรียกใช้ระบบอัตโนมัติของคุณเอง ฟีเจอร์นี้ปิดอยู่จนกว่าคุณจะเปิด
• มีให้เลือก 20 ภาษา สลับได้ทุกเมื่อในการตั้งค่า

เป็นส่วนตัวตั้งแต่การออกแบบ
• ไม่ต้องมีบัญชี ไม่มีโฆษณา ไม่มีการติดตาม ความก้าวหน้าของคุณอยู่บนพีซีของคุณ
• ส่งรายงานข้อขัดข้องเฉพาะเมื่อคุณอนุญาตเท่านั้น

Desk Pal ให้เคล็ดลับและการเตือนเพื่อสุขภาวะทั่วไป ไม่ใช่อุปกรณ์ทางการแพทย์ และไม่ให้คำแนะนำทางการแพทย์

## Features
- การเตือนอย่างอ่อนโยนให้ยืดเส้น ดื่มน้ำ พักสายตา และเดิน
- รอเมื่อคุณอยู่ในสาย ใช้ตัวช่วยโฟกัส หรือเปิดแอปเต็มหน้าจอ
- Bloop สาธิตท่ายืดเส้นแบบ 3D สด และตอบสนองเมื่อคุณเล่นด้วย
- เลือกการเตือนและเวลาได้เอง พร้อมแสดงค่าที่แนะนำ
- ไม่ต้องมีบัญชี ไม่มีโฆษณา ไม่มีการติดตาม: ความก้าวหน้าอยู่บนพีซีของคุณ

• แก้ไขข้อบกพร่องและปรับปรุงรายละเอียด
