# Desk Pal 1.2 Store listing: zh-cn

## Title
Desk Pal

## Hook
和 Bloop 一起，轻松提醒你拉伸、喝水、让眼睛休息

## Short description
住在托盘里的友好小伙伴，在适合你的时刻提醒你伸展身体、喝水、让眼睛休息、起来活动。

## Description
Desk Pal 是一位住在 Windows 托盘里的友好小伙伴，在你工作时帮你照顾好自己。

在办公桌前长时间工作，疲劳会慢慢累积：肩膀僵硬、眼睛酸涩、忘了喝水。Desk Pal 会在合适的时机轻轻提醒你伸展身体、喝水、让眼睛休息、短暂散步。开朗的蓝色小团子 Bloop 会演示每个伸展动作，盆栽小植物 Sprout 则会随着你完成每日目标而不断成长。

尊重你一天节奏的提醒
• 智能日程会合并提醒，不会让你被消息淹没，并把每小时的提醒次数控制在合理范围内。
• 当你正在通话、Focus Assist 开启或有全屏应用运行时，Desk Pal 会先等一等，再挑选更合适的时机。
• 你可以自己选择需要哪些提醒以及提醒频率。应用会显示推荐间隔，所有设置都可以调整。
• 护眼休息遵循广为人知的 20-20-20 法则，用安静的屏幕提示代替吵人的弹窗。

Bloop 和 Sprout
• Bloop 通过实时 3D 视图演示伸展动作，你戳一戳、摸一摸或和它玩耍时，它还会有反应。
• Sprout 会记录你的进度，让完成一次休息像是一个小小的成就，而不是任务。
• 没有负担：错过休息也不会有任何惩罚。

为你的桌面而设计
• 从托盘图标快速打开面板，用完整的应用窗口查看今日进度，还有简洁的设置页面。
• 跟随你的浅色或深色主题。
• 如果你希望休息或专注时间触发自己的自动化，可以配合 Automation Portal 使用。在你开启之前，此功能保持关闭。
• 支持 20 种语言，可随时在“设置”中切换。

隐私优先的设计
• 无需账户，没有广告，没有跟踪。你的进度只保存在你的电脑上。
• 只有在你允许时才会发送崩溃报告。

Desk Pal 提供一般性的健康小贴士和提醒。它不是医疗器械，也不提供医疗建议。

## Features
- 温和提醒你伸展、喝水、护眼和散步
- 通话中、Focus Assist 或全屏时自动等待
- Bloop 用实时 3D 演示每个伸展动作，陪它玩还会有反应
- 自选提醒和时间间隔，并显示推荐值
- 无需账户、没有广告、没有跟踪：进度只保存在你的电脑上
