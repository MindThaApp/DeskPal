# Desk Pal 1.2 Store listing: zh-hant

## Title
Desk Pal

## Hook

## Short description
住在系統匣裡的親切夥伴，在適合你的時機提醒你伸展、喝水、讓眼睛休息和動一動。

## Description
Desk Pal 是住在 Windows 系統匣裡的親切夥伴，在你工作時幫你照顧自己。

長時間坐在桌前，肩膀僵硬、眼睛疲勞、忘記喝水都會慢慢累積。Desk Pal 會在恰到好處的時機，輕輕提醒你伸展、喝水、讓眼睛休息和短暫散步。開朗的藍色小圓球 Bloop 會示範每個伸展動作，而盆栽小植物 Sprout 會隨著你達成每日目標而成長。

尊重你一天節奏的提醒
• 智慧排程會合併提醒，不會讓你被通知淹沒，每小時的次數也保持在合理範圍。
• 通話中、專注輔助開啟時，或有全螢幕應用程式執行時，Desk Pal 會先等待，再挑選更合適的時機。
• 自行選擇要哪些提醒以及頻率。畫面會顯示建議的間隔，所有項目都可以調整。
• 護眼休息採用廣為人知的 20-20-20 概念，以安靜的畫面提示取代吵雜的彈出視窗。

Bloop 和 Sprout
• Bloop 會以即時 3D 檢視示範伸展動作，你戳一戳、拍一拍或跟牠玩，牠都會有反應。
• Sprout 會記錄你的進度，讓完成休息像是一個小小的成就，而不是一件苦差事。
• 沒有罪惡感：錯過休息絕不會受到懲罰。

為你的桌面而設計
• 從系統匣圖示開啟快速面板，用完整的應用程式視窗查看今天的進度，還有簡單的設定頁面。
• 跟隨你的淺色或深色佈景主題。
• 若想讓休息或專注時間觸發你自己的自動化，可搭配 Automation Portal 使用。在你開啟之前，此功能預設為關閉。
• 支援 20 種語言，隨時可在 [設定] 中切換。

以隱私為設計核心
• 不需帳戶、沒有廣告、不追蹤。你的進度只會保留在你的電腦上。
• 只有在你允許時才會傳送當機報告。

Desk Pal 提供一般的健康福祉小提示和提醒。它不是醫療器材，也不提供醫療建議。

## Features
- 輕柔提醒你伸展、喝水、護眼和散步
- 通話中、專注輔助或全螢幕時會先等待
- Bloop 以即時 3D 示範每個伸展，並會回應你的互動
- 自選提醒和間隔，並顯示建議值
- 不需帳戶、沒有廣告、不追蹤：進度只保留在你的電腦上
